# AI-Based Rock Paper Scissors Game

## Project Overview
This project is an AI-based Rock Paper Scissors game where the user plays against the computer.

## Features
- User vs computer gameplay
- Random computer move generation
- Winner detection logic
- Score tracking system
- Interactive command-line game

## Technologies Used
- Python
- Random module
- Basic game logic

## How It Works
1. User chooses rock, paper, or scissors
2. Computer randomly selects a move
3. Program compares both choices
4. Winner is displayed
5. Scores are updated after every round

## How to Run
```bash
python rock_paper_scissors.py
